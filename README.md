# JavaCards
A Java application to simulate a deck of cards. Developed through Test Driven Development

## Details

For this simulation there will be 3 main classes: Card, Deck and Hand.
A Deck is an ordered list of cards, which will function as a stack (extend list).
A Hand will be a set of cards. In most cases ordering in is not necessary in a hand(extend set).
A Card will be identified by 2 variables: suit and rank (extend String)
Suit is a char chosen from C,D,H,S
Rank is a char chosen from the numerals 1-9 or the letters T,J,Q,K (Aces are 1)
i.e. C5 is the 5 of clubs, H1 ace of hearts, DT is the 10 of diamonds
